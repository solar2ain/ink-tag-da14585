# 硬件与功能说明

中文 | [English](hardware.en.md)

DA14585 固件面向盒马 AESL-2.9 与 AESL-4.2。屏型、方向、时区和显示内容通过共享 WebUI 或 CLI 配置，不使用平台专用客户端。

## 主板

| 项目 | 说明 |
| --- | --- |
| 主板型号 | `da14585_asel29`、`da14585_asel42` |
| 主控 | DA14585，96 KiB SRAM |
| 固件与图片存储 | 当前主板使用 256 KiB 外置 SPI Flash；其中 68 KiB 用于图槽 |
| 计时 | 板上 32.768 kHz 低频晶振 |
| 蓝牙名称 | 应用 `IKT_DA_XXXX`，Recovery `IKT_DA_XXXX_OTA` |
| 默认备注 | `InkTag XXXX`，与蓝牙名称分开 |

应用从 SPI Flash 加载到 SRAM 运行，不能把剩余 Flash 当成可执行应用扩展区。固件、BLE 状态、缓冲和栈共同使用 SRAM，因此文件未达到 OTA 上限也不代表运行内存充足。芯片与启动方式可参考 [Renesas DA14585 产品资料](https://www.renesas.com/en/products/da14585?partno=DA14585-00000AT2)和[SDK Flash 启动说明](https://lpccs-docs.renesas.com/Tutorial_SDK6/flash_prog.html)。

## 屏幕配置

| 屏幕 | 控制器与原生分辨率 | 配置说明 |
| --- | --- | --- |
| AESL-2.9 原屏 E029A33N8C380 / HINK-E029A33-A0 | SSD1619，128×296，BWR | asel29 完整镜像默认配置 |
| 盒马 2.13 英寸高分屏 | SSD1619，128×250，BWR | 按实际分辨率选择配置 |
| AESL-4.2 原屏 | UC8176，400×300，BWR | asel42 完整镜像默认配置 |
| ZKC42VM / ZKV42VM 4.2 英寸换装屏 | SSD1683，400×300，BWR | 使用 SSD1683 配置，不沿用原屏控制器 |
| 华为 3.98 英寸 A0 | JD79665AA，768×552，BWRY | 四色直接传图；完整帧超过图槽容量 |

支持范围必须同时匹配控制器、recipe、颜色、原生尺寸和可视区域。相同英寸或分辨率不能证明控制器兼容。原生 128×296 屏横向使用时，高度只有 128 像素，采用紧凑日历布局；布局按有效宽高选择，不按“2.9 英寸”名称选择。

## 图槽容量

图槽按当前完整帧、96 字节图片头和 4 KiB 扇区对齐计算：

`数量 = floor(68 KiB / align_up(完整帧字节数 + 96, 4 KiB))`

| 配置 | 完整帧 | 单槽占用 | 参考数量 |
| --- | ---: | ---: | ---: |
| 128×250 BWR | 8,000 B | 8 KiB | 8 |
| 128×296 BWR | 9,472 B | 12 KiB | 5 |
| 400×300 BWR | 30,000 B | 32 KiB | 2 |
| 768×552 BWRY | 105,984 B | 超过图片区 | 0 |

以设备报告的容量与可用槽为准。RLE 在传输后解码为完整帧，不增加图槽容量。大屏容量为零时仍可直接传图，但无法保存或自主轮播。

图槽 ID 稳定，删除后可以有空位。名称最多 35 个 UTF-8 字节，名称和类型在上传或替换时保存，不提供独立编辑。替换为原地写入，中途断电可能丢失该槽旧图片；更换屏幕几何或存储跨度后需要重新整理图片。

板卡页可读取出厂默认和当前生效的屏幕信号引脚，并修改 MOSI、CLK、CS、DC、RESET、BUSY 和可选 EN。保存后持久生效，“恢复默认引脚”只移除引脚覆盖，不改日历等设置。出厂默认引脚由完整烧录配置决定；Flash、SWD 和固定 BS 等保护信号不能重分配，EN 极性可配置。六个屏幕信号与 EN 全部设为未使用可关闭显示，蓝牙配置仍可用。引脚必须对应芯片封装上实际存在且已接线的 GPIO。

正方形、接近方形和方形可视区域使用普通矩形模板。屏幕配置仍需匹配支持的控制器、配方、颜色、对齐、尺寸和可视边界。

## 电压、温度与供电

有效电压不高于 2.6 V 时，支持红色的屏幕将电池图标显示为红色；这不改变 Flash 写入或 OTA 的低压保护。

设备提供电压读数，用于查看供电状态；它不是校准电池电量表。读数不可用时显示不可用，不显示为零。

温度来自支持回读的屏幕控制器，不是 MCU 温度。正常刷新会采样，缓存有效期为 15 分钟；连接测温在缓存无效且屏幕空闲时采样。忙碌、读取失败或控制器不支持时显示不可用。

电池老化、长线、接触不良和串联电流表的压降可能使 Flash 写入失败。错误也可能来自存储或通信异常，应先读状态、检查供电，再定位原因，不降低低电门限。

## 功能

固件提供的功能包括日历、时钟、设备信息、直接传图、图槽管理与自主轮播。设备页显示蓝牙名称、主板型号、品牌和内置产品二维码；设备备注可通过客户端修改。

支持清除设置和清除用户数据，两者不互相替代。支持签名 OTA 与 Recovery 安全返回；App-only OTA 不替代固定 Recovery、启动加载器或字体更新。

计时使用板上低频晶振。初次使用、更换电池或断电后请校时。
